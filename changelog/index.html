TillNext: Paycheck Planner Changelog

Public notes for meaningful TillNext changes. This page focuses on user-facing updates, privacy posture, and support information.

Version 1.0, Pre-Launch

Updated: May 3, 2026

  • Added bottom clearance to Today Check so the final rest-of-month day stays visible above the tab buttons.
  • Kept Today Check card payback action pills on one line, including rows with Date, Next, Paid, and Remove actions.
  • Added Today Check controls to delete an extra separate balance, including clearing those item assignments back to Cash.
  • Added a custom date picker for Today Check card paybacks so payback dates can be chosen, changed, or cleared.
  • Changed Today Check from a 14-day view to the rest of the current month, including the purchase check timeline.
  • Capped Today Check safe cash so it cannot show more than Home says is left after the current month's plan.
  • Fixed Today Check duplicate rows when cached Home months reused the same recurring bill source.
  • Added a Settings toggle for an optional Today tab and included Today Check diagnostic rows in the existing CSV export.
  • Fixed Today Check card paybacks so old duplicate generated rows are repaired and each payback can be removed directly.
  • Fixed Today Check card payback cleanup so switching an item back to Cash removes the generated payback.
  • Fixed Today Check available cash so it uses the latest Home balance and includes current-month Home expenses.
  • Fixed Today Check so pending Home expenses, including overdue items, are included in safe-cash calculations.
  • Removed unfinished future expense and savings planning references so TillNext focuses on paycheck timing, recurring bills, and one-time items.
  • Improved Settings reliability during pre-launch testing so support checks open without blocking the app.
  • Added lifetime unlock purchase access in Settings so the one-time TillNext unlock can be started from inside the app.
  • Improved bottom tab responsiveness, removed unreliable horizontal tab swipes, and kept lower screen content reachable above the tab buttons.
  • Improved Home refresh performance when planner data changes, keeping totals and notices current while reducing unnecessary work.
  • Improved widget quick-add buttons so they stay readable when the Home Screen widget is customized with tinted or clear rendering.
  • Made the darker app icon the default and added a Settings picker to switch between the darker and lighter Home Screen icons.
  • Updated public screenshots with Light Mode, Dark Mode, real small, medium, and large Home Screen widget examples, and Home wording comparison examples from the iPhone simulator.
  • Removed the Next income line from the Home Screen widgets so the layouts stay cleaner.
  • Changed the Settings planning switch to Disable Match Bank, with Match Bank available by default.
  • Moved the Home undo banner closer to the bottom controls and added a direct way to open the recent undo picker from the banner.
  • Added a larger Till Next widget that shows the next few Home items, and simplified the small and medium widget layout so it no longer has a smaller card inside the widget.
  • Fixed the Home Screen widget so its Till Next amount matches Home and its colors follow the iPhone's Light or Dark Mode.
  • TillNext now follows the iPhone system appearance for Light and Dark Mode, and the separate Dark Mode setting has been removed.
  • Added a Till Next Home Screen widget with quick buttons for one-time income and expenses.
  • Updated the Till Next widget to look more like the Home screen, including the same calm card style and positive, neutral, or warning balance color.
  • Added display settings for the month picker position and planning settings for hiding Match Bank.
  • Expanded the privacy policy with EU, EEA, and UK privacy rights, retention, support request, and local data control details.
  • Added public Terms of Use and aligned the in-app terms and privacy notes with the GDPR privacy wording.
  • Set the first public App Store release candidate to version 1.0.
  • Confirmed the public App Store name as TillNext: Paycheck Planner, with the shorter TillNext name kept for the iPhone Home Screen.
  • Set the final App Store bundle identifier to com.whiptail.TillNext before developer account enrollment.
  • Configured the official TillNext support email at support@tillnext.app.
  • Confirmed v1 device support as iPhone with iOS 17 or later.
  • Changed the first-run Terms & Privacy gate to a short consent summary with the full terms still one tap away.
  • Added a public Help & FAQ page with screenshots and common tasks.
  • Added a public support page, privacy policy, and changelog for App Store review and customer reference.
  • Added in-app support links for private email support and public technical issue reports.
  • Kept TillNext local-first with no account, no external connectors, no Google integrations, no ads, and no analytics tracking.
  • Added Terms & Privacy review during first launch and as a small link at the bottom of Settings.
  • Added a local 30-day full-editing trial followed by a one-time lifetime unlock through the App Store.
  • Added Recurring tab month navigation so future-starting recurring items can be viewed before their month arrives.
  • Added past occurrence history for recurring income and recurring expenses.
  • Improved recurring item details so opening an item from another month shows that month's occurrence date.
  • Improved recurring expense rows so they show the selected month's expense days next to the cadence, such as Monthly • 25 or Twice a month • 1 & 15.
  • Added a Today shortcut beside income and expense date pickers for faster one-time and recurring entry.
  • When saving same-day one-time income or expenses, TillNext now offers to keep the item Pending or mark it Done/Paid.
  • Preserved CSV export and local reset from Settings.
